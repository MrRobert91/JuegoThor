# Thor Endless Runner

![Thor](assets/thor.png)

## Descripción
**Thor Endless Runner** es un emocionante juego de plataformas y acción para navegador. Toma el control de Thor, el Dios del Trueno, mientras corre incansablemente enfrentándose a diversos enemigos y obstáculos del reino nórdico.

### Características:
- **Acción frenética**: Salta y ataca para sobrevivir el mayor tiempo posible.
- **Enemigos variados**: Enfréntate a diferentes criaturas y villanos como Loki.
- **Multimedia**: Incluye cinemática de introducción y una banda sonora épica.
- **Portabilidad**: Ejecutable directamente desde el navegador gracias a su tecnología HTML5.

### Controles:
- **Espacio / Toque**: Saltar
- **Z / Clic**: Atacar
